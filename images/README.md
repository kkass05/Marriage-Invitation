# Папка для фотографий

Положите сюда два файла (см. `syrga-salu-landing-plan.md`, раздел 3):

- `nevesta.jpg` — фото рук невесты с украшением (используется в hero-блоке).
- `shanyrak.jpg` — фото шаңырақа с кистями (используется в блоке-разделителе).

Пока файлов нет, сайт использует мягкий кремово-золотой градиент вместо фото (не сломан, но без фото выглядит проще).
